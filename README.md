# 🇧🇩 BD.LIVE — Bangladesh Real-Time Nation Dashboard

A real-time dashboard for Bangladesh featuring:

- **🗺️ Interactive Map** — 64 districts with hover/click details
- **💰 Food Prices** — WFP commodity prices across 15+ items
- **📍 Location Explorer** — 8 divisions, 64 districts, 491 upazilas
- **🏛️ Citizen Services** — 20+ government services directory
- **🌤️ Weather Dashboard** — Live weather for 20 major cities
- **📊 Open Data Explorer** — Browse all datasets

## Live Site

[https://bd-live-dashboard.netlify.app](https://bd-live-dashboard.netlify.app)

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Leaflet.js
- **Data:** WFP Food Prices, OpenWeatherMap API
- **Hosting:** Netlify
- **CI/CD:** GitHub Actions (daily auto-updates)

## Auto-Updates

Weather data is refreshed daily at 6:00 AM BST via GitHub Actions.
